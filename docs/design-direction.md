# 设计方向

## 品牌

- 产品名：**CoDone**
- 中文副标题：**一起把事办完**
- 品牌图标：两条勾线组成一个 C；不使用 Apple 或微信官方 Logo。

## 当前原型与下一版

`prototype/index.html` 是早期的双手机概念验证版，包含演示控制面板，主要用于验证：

- 邀请好友 → 聊天任务卡
- 好友订阅 → 服务通知
- 任务完成 → 进度同步
- 空态、加载、错误和订阅状态

下一版原型不再保留双手机和演示控制，改成：

- 一台 393×852 手机壳，居中放在柔和环境光背景上
- 手机外不出现标题、说明、按钮或控制面板
- 所有页面切换、弹层和通知都在手机内完成
- 视觉方向为 iOS 液态玻璃 / 毛玻璃

## 视觉方向

关键词：液态玻璃、半透明层级、柔和环境光、细边框、克制阴影、真实微信聊天感。

玻璃材质建议：

```css
background: linear-gradient(135deg, rgba(255,255,255,.68), rgba(255,255,255,.34));
backdrop-filter: blur(28px) saturate(180%);
-webkit-backdrop-filter: blur(28px) saturate(180%);
border: 1px solid rgba(255,255,255,.72);
box-shadow:
  0 18px 48px rgba(31,38,135,.14),
  inset 0 1px 0 rgba(255,255,255,.92);
```

玻璃只用于：顶部导航、清单摘要、任务卡、TabBar、底部弹层、服务通知。正文列表保持足够不透明度，避免文字被模糊影响。

## 颜色与字体

- 主文字：`#0B1220`
- 次要文字：`rgba(11,18,32,.62)`
- 主色：海玻璃绿 `#0B7A6B`
- 辅助色：珊瑚橙 `#FF8A65`
- 错误色：`#D92D20`
- 字体：`-apple-system, BlinkMacSystemFont, "SF Pro Display", "PingFang SC", "Microsoft YaHei", sans-serif`
- 字号：标题 34px、页面标题 28px、卡片标题 20px、正文 15～16px、辅助 12～13px
- 间距：8px 基准
- 圆角：卡片 20～24px，弹层 32px，胶囊 999px
- 触控目标不小于 44×44px

## 页面范围

| 页面 | 作用 |
|------|------|
| P1 今日 | 跨清单聚合今天/本周任务 |
| P2 清单 | 所有我创建或参与的清单 |
| P3 清单详情 | 成员、任务、进度、邀请 |
| P4 任务详情 | 负责人、截止时间、订阅状态、完成 |
| P5 新建/编辑任务 | 创建任务、指派、设置提醒 |
| P6 邀请/加入 | 分享卡片、好友确认加入 |
| P7 微信聊天 | 单聊/群聊任务卡、服务通知、@提醒 |
| P8 通知中心 | CoDone 内提醒与协作动态 |
| P9 我的/设置 | 提醒状态、清单关系、帮助 |

## 交互原则

- 所有操作在手机内完成，不出现任何外置演示控制。
- 分享 → 聊天 → 任务详情 → 订阅 → 服务通知 → 完成，整条链路可走通。
- 好友没订阅时，不出现服务通知，不伪造成功。
- 一次订阅只发送一条提醒，发送后显示“需重新订阅”。
- 动效 0.24s ease，只使用透明度和位移动效。
- 不在正式产品中出现“模拟到期”“重置演示”“演示控制”等入口。

## 设计禁忌

- 不要第二台手机、侧边控制面板、手机外说明文字。
- 不要大面积绿色 hero、整屏绿色按钮、每张卡片发光。
- 不要高饱和彩虹渐变、紫色科技风、霓虹、3D 插画、emoji。
- 不要把玻璃模糊到正文不可读。
